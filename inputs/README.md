# Inputs

`geometry/nasa_eet_ar12_original.vsp3` is the original NASA/OpenVSP reference
received by the project. `geometry/baseline_corrected.vsp3` is the common
wing-only baseline after the inserted-airfoil interpolation audit and should be
used for new work.

The corresponding public tunnel report is NASA TP-1580, NTRS record
`19820007142`. The report PDF is not duplicated in this repository.

Confirm redistribution rights for the `.vsp3` files before making the repository
public.
