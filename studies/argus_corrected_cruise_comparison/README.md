# ARGUS Post-Audit Corrected Cruise Comparison

This project reruns the Mach 0.78 early/late-cruise comparison after the July
2026 geometry and dimensional-data audit. It is independent of, and does not
overwrite, the historical `argus_cruise_comparison` outputs.

- corrected rigid source geometry generated by the audited interpolation
  script;
- continuous trailing-edge and distributed-twist geometries generated from
  that same corrected baseline;
- physical early- and late-cruise lift targets at Mach 0.78;
- aircraft-scale SI strip loads and half-wing root bending;
- no hinge-moment constraint.

The study compares trailing-edge and twist morphing using the same:

- NASA EET cruise-wing geometry;
- outer-wing interval, `0.60 <= eta <= 1.00`;
- early- and late-cruise flight states;
- fixed target lift;
- absolute half-wing root-bending constraint;
- smooth spanwise interpolation and strict validation procedure.

The conventional hinged reference will be regenerated separately from the
same corrected baseline and merged into the final four-concept summary.

## Scale conventions

The source OpenVSP model is the 12-ft NASA wind-tunnel model. OpenVSP stores
its native geometry in feet. Two scales are kept explicitly:

1. `wind_tunnel`: one OpenVSP model unit equals one foot (`0.3048 m`);
2. `aircraft`: the geometry is treated as geometrically similar and scaled so
   that the NASA reference area of `12 ft^2` becomes `122.6 m^2`.

VSPAERO is run on the native geometry with the published NASA reference
quantities. Dimensionless coefficients are scale independent. Dimensional
loads are reconstructed using the selected metres-per-model-unit scale and
the physical dynamic pressure of each flight state.

## Operating points

The demonstration conditions are:

- early cruise: mass-equivalent lift `74,500 kg`, altitude `10,000 m`,
  Mach `0.78`;
- late cruise: mass-equivalent lift `56,000 kg`, altitude `12,000 m`,
  Mach `0.78`.

Atmospheric properties use the 1976 ISA troposphere/lower-stratosphere model.

Mach 0.78 is the ARGUS mission condition. NASA TM X-71996 provides a separate
transonic validation anchor at design CL 0.60, measured drag-rise Mach 0.802,
and unit Reynolds number 16.4 million per metre. The tunnel condition does not
replace the ARGUS operating points.

## Audit status

The source model is `baseline_corrected.vsp3`. Original airfoil sections are
preserved; only inserted sections are blended between their original brackets
on a common cosine-spaced x/c grid. The former 1050 N m hinge-moment proxy is
not evaluated or constrained. All absolute spanwise loads are reconstructed in
aircraft-scale SI units from native dimensionless VSPAERO strip coefficients.

## Run the foundation checks

```powershell
python scripts\01_build_study_manifest.py
python -m unittest discover -s tests
```

Run the strict rigid-baseline trims at both physical cruise states with:

```powershell
<OPENVSP_PYTHON> `
  scripts\02_run_rigid_baseline_states.py --force
```

The aerodynamic solve uses the native NASA-model reference quantities.
Spanwise coordinates and chords are then converted to the target-aircraft scale
before integrating lift and root bending moment in SI units.

Generated results are written below `outputs/`. Existing projects and results
are never overwritten.
