# Curated results

This directory contains the final audited summary tables, selected geometries,
and a small set of report figures. It intentionally excludes the full solver
database.

- `cruise/`: Mach 0.78 early/late cruise results ranked by `CDiw`.
- `low_speed/`: corrected Mach 0.10 fixed-CL comparison.
- `geometries/`: representative `.vsp3` files for downstream inspection.
- `figures/`: publication figures in PDF form.

The full native VSPAERO archive remains in the project archive. Do not treat an
included geometry as actuator-feasible merely because it is aerodynamically
feasible under the illustrative constraints.
